Data coverage seen so far

Learned in this browser from the matches you open, refresh or scan. A tag shows in the lists once a league has been seen in 2 matches. Matches only count when the statistics call worked.

Optional. With a key, Live matches on the Bet tab fills the minute, score, shots on target, xG and last-5 average total goals (scored plus conceded) for you. The key stays in this browser and is sent only to api-sports.io. It is never part of a copied record. Each refresh uses 2 requests. The Backtest tab uses the same key.

Optional. A small server of your own (a Cloudflare Worker) watches live matches with your API-Sports key and sends an alert to your lock screen or desktop when a match passes your rules, for example BET UNDER 3.5 · Arsenal v Chelsea · 62' · 1–1. It looks about once a minute and sends one alert per match. It uses your Market choice and entry minutes, and stays quiet while the panel is paused, in cool-off, or done for the day. Your API key is kept on your own server, so keep its address and password to yourself. On iPhone this works only from the Home Screen app. On a computer it works in Chrome, Edge, Firefox and Safari while the browser is open (a minimised window is fine). Up to five devices can be on at once and each gets every alert. Only one of them needs to set the rules: a device that joins a server that already has rules just receives alerts, until you tick the box above.

Each Home Screen icon and each browser keeps its own data, and a new one starts empty. Copy a backup first, keep it in Notes, then paste it into the new icon or browser. It holds your session, rules, record and history. It does not hold your API key or alert password.
